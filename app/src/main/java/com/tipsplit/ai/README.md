# Tip-n-Split AI — Android

Short description: Tip‑n‑Split AI mobile app (Android) — bill splitting + payments + AI features.

## Getting started

1. Install Android Studio Arctic/Chipmunk+ and JDK 11 or 17.
2. Clone repo: `git clone <repo-url>`
3. Add `local.properties` with `sdk.dir` or configure in Android Studio.
4. Build: `./gradlew assembleDebug`

## Secrets & signing
- Do NOT commit keystore or API keys. Use environment variables or GitHub Secrets for CI.

## Contributing
- Branching: `main` = production, `develop` = active development. Use feature branches `feature/<name>`.
- Open PRs for changes, add screenshots for UI changes.
